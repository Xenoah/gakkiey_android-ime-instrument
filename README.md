# 楽器キー (GakkiKeys)

Androidのキーボード（IME）がそのまま楽器になります。🥁ドラム / 🎹鍵盤（ピアノ＋シンセ）/ ⌨文字入力（キーごとにランダム効果音、テンキーはDTMF）。
音源ファイルは使わず、すべてリアルタイム合成（低遅延 AudioTrack, float PCM）。外部ライブラリなし・Javaのみ。

## ビルド
- **GitHub Actions**: pushすると `Build APK` が実行され、Artifacts に `GakkiKeys-apk` が保存されます。`main` にアプリ本体・ビルド設定の変更がある場合は、ビルド成功後に次のパッチ版（例: `v1.0.0` → `v1.0.1`）をGitHub ReleasesへAPK付きで自動公開します。READMEやCI設定だけの変更では新規Releaseを作成しません。
- **バージョン**: 自動公開時に最新のGitタグを参照して `versionName` と `versionCode` をAPKビルドに反映します。公開前にローカルのGradle設定を書き換える必要はありません。
- **APK署名の注意**: 現在のrelease APKはCI環境のデバッグ鍵で署名しています。ビルドごとに鍵が変わりうるため、前版APKへの上書き更新は保証できません。上書き可能な正式配布を行うには永続的な署名鍵を安全に管理する必要があります。
- **ローカル**: Android Studio で開いて Run、または `./gradlew assembleRelease`。

## 使い方
1. アプリ「楽器キー」を開く → ①でキーボード設定から有効化 → ②で切り替え
2. 任意の入力欄をタップ

| モード | 操作 |
|---|---|
| 🥁 ドラム | TR-808風の音で、実際のドラムセットの配置（クラッシュ・ハイハット・スネア・タム2つ・フロアタム・キック・ライド・カウベル＋CLAP/808パッド）。ハイハットは中央=クローズ／外周=オープン、スネアの外周=リムショット。中心ほど強い。⚙でGM順パッド・種類別パッド（4×3）にも変更可 |
| 🎹 鍵盤 | ⚙で音色（ピアノ / LEAD / SQUARE / PAD / BASS）と幅（1 / 1.5 / 2 / 3オクターブ、標準1）。ピアノ=手前ほど強い・スライドでグリッサンド・SUSでペダル。シンセ=縦で明るさ・横スライドでポルタメント |
| ☎ 電話機 | 緑の公衆電話風。緑の筐体＋黒パネル、左に液晶（押した番号）・C（全消去）・⌫・スピーカー網、右に 1 2 3 / 4 5 6 / 7 8 9 / ＊ 0 ＃ の銀色丸ボタン（黒リング＋黒の丸文字）。押している間DTMFが鳴りオレンジに光る。「✎」ONで数字を入力欄にも入力 |
| 🗣 声 | 英語の発音記号（IPA 44音素：母音12・二重母音8・子音24）キーボード。押すとその音をフォルマント合成で発音（母音・伸ばせる子音は押している間のばす）。押した記号は下の欄にたまり、▶で単語として連続発音（ˈ で強勢、␣ で区切り）。欄タップでクリア。「✎」ONで記号を入力欄にも入力 |
| ⌨ 文字入力 | QWERTY。「A æ」キーで英字 ⇔ 英語の発音記号（IPA 44音素）を切替。英字はキーごとにランダムな効果音（18種×音程）、発音記号は押すとその音を発音。123 = 電話型テンキーでDTMF、#+= = 記号。日本語入力はなし |

### ⚙ メニュー
上部のタブ（✨ 全体 / 🥁 ドラム / 🎹 鍵盤 / ☎ 電話機 / 🗣 声 / ⌨ 文字入力）でどの設定か切り替え。開くと今のモードの設定が出る。
- ✨ 全体：光（OFF / タッチ = 押した所から光の輪 / タッチ＋音 = 音の大きさでキーボード全体と縁が光る）、振動（OFF / タップ / 音圧 = 実際の音の大きさに合わせて振動の強さが変わる）
- 🥁 ドラム：配置（**リアル** = 実際のドラムセット配置 / GM順パッド = GMの並びを下段から詰めた4×3パッド / 種類別パッド = 上段シンバル・中段タム・下段キック/スネアの4×3パッド）、強弱（位置で強弱 / 一定）
- 🎹 鍵盤：音色 / 幅（1〜3オクターブ、標準1）/ 表示（ドレミ・CDE・なし）
- ☎ 電話機：プッシュ音の音量（小・中・大）
- 🗣 声：声の種類（男性・女性）、声の高さ（低い・普通・高い）
- ⌨ 文字入力：タイプ音（OFF・小・中・大、🎲でシャッフル）/ テンキー音（DTMF ON/OFF）

リアル配置（標準）：上段 CRASH・TOM 1・TOM 2・RIDE（中央上にCOWBELL）、下段 HI-HAT（中央=閉／外周=開）・SNARE（外周=リム）・KICK・FLOOR、右端にCLAP / 808の電子パッド。

GM順パッドの配置：
```
TOM H   CYMBAL  COWBELL  BOOM
TOM L   C.HAT   TOM M    O.HAT
KICK    RIM     SNARE    CLAP
```

種類別パッドの配置：
```
CYMBAL  O.HAT   C.HAT    COWBELL
TOM H   TOM M   TOM L    BOOM
KICK    SNARE   CLAP     RIM
```

### 文字入力モード
- 「A æ」キー：今の言語が光る（A = 英字、æ = 発音記号）。発音記号モードでは ˈ（強勢）と / も入力できる。
- パスワード・メール・URL欄では自動で英字、数字・電話欄では自動でテンキー。
- 日本語入力はありません（日本語は🌐でGboardなどに切り替え）。

- ◀ ▶ でオクターブ、`✎` で「鳴らした音を文字入力」(ドレミ / ドンタン…)、🌐 タップで次のIME・長押しで選択、▼で閉じる
- 音量はメディア音量

## 構成
- `SynthCore.java` – Android非依存のシンセ本体（ボイス32, ドラム12種, 加算合成ピアノ, polyBLEP+SVFフィルターのシンセ, 簡易リバーブ）
- `SoundEngine.java` – AudioTrack（PERFORMANCE_MODE_LOW_LATENCY）で再生するオーディオスレッド
- 最適化：エンベロープの指数関数は表引き、無音が4秒続くとDSPを止める、描画のグラデーションはキャッシュ
- `InstrumentView.java` – 描画とマルチタッチ
- `GakkiIME.java` – InputMethodService
- `SetupActivity.java` – 有効化ガイド＋試し弾き欄
